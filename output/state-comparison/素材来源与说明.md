# 威朗普表情同步对照视频

成片：`Willump_表情同步对照.mp4`

- 左侧：用户提供的 IMG_5162.mov，保持完整画面、顺序、速度和原声；左下角增加随相机移动的屏幕放大窗口。
- 右侧：随录像中的状态切换对应图片；思考表情的张嘴、闭嘴帧也随录制画面切换。
- 输出：1920×1080、30 fps、H.264 MP4；原片的立体声 AAC 音轨直接复制。原片约 40.61 秒，输出视频帧约 40.60 秒。
- 时间轴按录像每 0.1 秒抽样核对，切换点精度约 0.1 秒。状态名称依据本项目的表现映射。
